01 / ABOUT ME

Engineering with a security mindset.

I work at the intersection of product engineering and application security. My focus is designing useful software, testing its trust boundaries and building evidence-based improvements.

My practical work spans Android applications, API authorization, secure authentication, cloud-connected services and developer tooling. I use authorized labs and owned projects to explore weaknesses, validate fixes and communicate findings clearly.

I value reproducible evidence, maintainable code and honest project status. A pilot is a pilot; a hypothesis is not a confirmed vulnerability; an unreleased application is not a production launch.
